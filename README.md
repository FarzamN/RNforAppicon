Installation
git clone[<your-repository-url>](https://github.com/FarzamN/RNforAppicon.git)
cd RNforAppicon

Install dependencies:
npm install

# or

yarn install

Install iOS pods (for iOS):
cd ios && pod install && cd ..

Start the Metro bundler:

npm start

# or

yarn start

Run on iOS simulator:
npm run ios

# or

yarn ios
